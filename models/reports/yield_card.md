## Limitations

- Rows are **state-level annual aggregates**, not fields. A prediction is a regional expectation, never a guarantee for one farm.
- `Production` is excluded as a feature: Production is excluded: Yield == Production / Area in this dataset. Any published R2 above ~0.9 for this dataset is measuring that leak.
- Crops dropped for non-tonne units: Coconut.
- Fertilizer and pesticide inputs default to State x Crop medians when the farmer leaves them blank; the result reports which values were used.
